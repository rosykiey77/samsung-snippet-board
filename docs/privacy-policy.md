# Kebijakan Privasi — Snippet Board

_Berlaku sejak versi 1.0.0 · 7 November 2026_

**Singkatnya: Snippet Board tidak mengumpulkan, mengirim, atau membagikan data apa pun.**

- **Tanpa jaringan.** Aplikasi tidak meminta izin Internet. Tidak ada server, akun, iklan, analitik, pelacakan, atau pelaporan crash.
- **Data hanya di perangkat.** Snippet, kategori, dan nilai variabel (`{nama}`, `{rekening}`) disimpan di database lokal di penyimpanan internal aplikasi, yang tidak dapat dibaca aplikasi lain.
- **Tanpa backup otomatis.** Backup cloud Android dinonaktifkan. Data hanya keluar dari aplikasi jika Anda sendiri memakai *Ekspor data* ke file pilihan Anda (file itu berisi nomor rekening tanpa masking).
- **Clipboard.** Aplikasi hanya menulis ke clipboard saat Anda mengetuk snippet, dan tidak pernah membaca atau memantau clipboard. Snippet kategori Rekening ditandai sensitif agar pratinjau clipboard disamarkan (Android 13+).
- **Pembelian Pro.** Pembelian dan pemulihan diproses oleh aplikasi Galaxy Store milik Samsung sesuai kebijakan privasi Samsung. Snippet Board hanya menerima status "Pro / bukan Pro" dan menyimpannya di perangkat.
- **Izin.** Getar (haptic saat menyalin), tampil di atas aplikasi lain dan notifikasi (hanya bila Anda mengaktifkan tombol mengambang), serta izin billing Galaxy Store.
