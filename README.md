# samsung-snippet-board
One UI Quick Snippet & Clipboard with Samsung Edge Panel integration for Galaxy Store.

## Features (MVP)
- **1-Tap Quick Copy**: Instant snippet copying with One UI styling.
- **Categorization**: Personal, Work, Bank Accounts, Chat Templates.
- **Dynamic Variables**: Fill `{name}`, `{date}`, `{amount}` on the fly.
- **Samsung Edge Panel Support**: Access clipboard snippet drawer anywhere via Slook SDK.
- **100% Offline & Private**: Zero tracking, local SQLite database storage.
